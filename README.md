A one-line weather forecast for Drizzleport, a city that doesn't exist: light rain all day, heavy rain all night, and a flood warning for your weekend plans.

## Run it

```bash
python3 main.py
```

This writes the entry line to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`), exactly one line with no trailing newline.
